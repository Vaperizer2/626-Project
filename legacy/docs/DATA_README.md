# Data lives next to wherever you run the notebook (`./data`).

## Manual drop (no Kaggle API)

1. Download [Electronic Component Recognizer](https://www.kaggle.com/datasets/mdfaisalahmed025/electronic-component-recognizer).
2. Put the zip in `raw/`, **or** extract to class folders:

```text
raw/<anything>/
  Resistor/
  Capacitor/
  ...
```

3. Run the data cell in the notebook.
