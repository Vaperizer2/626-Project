## Decisions and next runs

1. Keep the original ResNet18 checkpoint as the baseline; do not overwrite it.
2. ResNet50 is the current raw-test leader at 0.6845 accuracy / 0.6640 macro-F1, but it remains below the 80–90% target.
3. The completed scratch-CNN variants are all weak (best validation macro-F1 0.1817; selected raw-test accuracy 0.2275), so none should be promoted. The width-64 variant was intentionally skipped.
4. Use the high-loss audit to review training noise and class ambiguity, but never use raw test labels to tune a model.
5. The model error audit confirms that scratch CNN capacity is not a viable path: on the test set ResNet50 was correct on 247 images that the scratch CNN missed, while the scratch CNN was uniquely correct on only 8. Prioritise training-only review of the low-recall pretrained classes before another architecture trial.
6. The completed pre-registered family/size sweep used `12_model_family_benchmark.py`; it selected on validation macro-F1, saved progress after every validation pass, and evaluated the held-out test only for the final selected model. ConvNeXt-Tiny led validation and reached 0.6979 raw-test accuracy; the >80% target was not reached. The next phase must remain validation-first and must not tune on this test result.
7. The larger validation phase is complete: ConvNeXt-Small won its phase at macro-F1 0.7266, but ConvNeXt-Tiny remains the global validation leader at 0.7427. Because phase 2 was run with `--defer-test`, no additional test labels were consumed.
8. The next safe phase is pre-registered as ConvNeXt-Base, EfficientNet-V2-M, and Swin-B. Run it with `--defer-test`, compare its validation winner against the global ConvNeXt-Tiny leader, and only then perform one final held-out-test evaluation if a new global validation leader emerges.
9. The largest-model phase is complete: ConvNeXt-Base led that phase at macro-F1 0.7407, but ConvNeXt-Tiny remained the global validation leader at 0.7427 at that point. No phase-3 test labels were read; the subsequent recipe and curation phases are logged below.
10. The strong-recipe phase completed validation-first: ConvNeXt-Base reached validation macro-F1 0.7473 without an overfit flag and became the first new global validation leader. Its one permitted raw-test evaluation reached 0.7132 accuracy / 0.6969 macro-F1, below target. ConvNeXt-Tiny reached 0.7366 macro-F1 under the same recipe.
11. The pre-specified TTA-logit ensembles all trailed the single strong ConvNeXt-Base validation score (best ensemble macro-F1 0.7415), so no ensemble test labels were read. Keep the ensemble runner for reproducible future checks, but do not promote an ensemble from these results.
12. The accuracy-focused ConvNeXt-Base recipe reached validation macro-F1 0.7317 with a smaller 0.2090 gap and did not beat the strong recipe. It was correctly left test-deferred.
13. The final safe trial used the four reviewed `train-*` exclusions from `data/curation/reviewed_exclusions_v1.json`; validation and test membership remained unchanged. It reached validation macro-F1 0.7421 at epoch 16 with a 0.2351 gap, below the strong ConvNeXt-Base leader at 0.7473, so no test labels were read.
14. The bounded architecture/recipe search is complete for this contract: 14 model-family/size candidates, three training recipes, four pre-specified ensembles, and one conservative training-only curation trial were checkpointed and compared validation-first. The best permitted raw-test result is 0.7132 accuracy; the >80% target was not reached.
15. The eight-model Optuna follow-up is complete on `ai-pc-04` with five nominal trials per candidate, 15 epochs, and validation macro-F1 selection. ConvNeXt-Tiny reached 0.742929, only 0.000229 above its logged reference and below the strong-recipe ConvNeXt-Base at 0.7473. The test split was not loaded, so no additional test labels were consumed. The synchronized report is `notebooks/outputs/metrics/family_hparam_tuning_v3.json` and the study is `notebooks/outputs/metrics/family_hparam_v3.db`.
16. Dataset research now identifies evaluation contamination as the main blocker: 128/522 validation rows and 115/523 test rows have exact byte-identical copies in training, and 12 duplicate groups have contradictory labels. Treat the legacy raw test as an audit set and prioritize a new immutable, deduplicated, group/source-disjoint dataset contract.
17. The OpenCV research path should begin with a classical, abstaining resistor-band decoder behind the component classifier. Do not describe decoded nominal resistance as a measured electrical value; add a learned secondary model only after collecting representative band/value/tolerance annotations.
