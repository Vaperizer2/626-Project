The patched GPUI runtime compiler reads HLSL embedded in the executable instead
of an absolute source path on the build machine. This targets the reported GUI
startup crash; native Windows GUI validation is still pending. Extraction and
all six models' inference already worked in the original reviewer test.

Please try Classify, Demo and Benchmark, then report the Windows version, GPU,
failing action and terminal output if the GUI still fails. Headless checks:
    run.bat models --check
    run.bat classify --model all demo_stack\01_battery_holder.jpg

run.bat forwards arguments, uses the bundled CPU ONNX Runtime and returns the
application's exit code. It pauses after a no-argument/double-click launch and
on GUI failure so errors stay readable; CLI commands never pause. For scripted
GUI runs, first set COMPCLASS_NO_PAUSE=1. From another batch file, use CALL when
invoking run.bat so control returns to your script.
