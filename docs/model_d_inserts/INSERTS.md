## What model D is

A fourth main model trained and scored by the course pipeline exactly as model C, with a smaller backbone.

| | C (in the report) | D (proposed) |
|---|---|---|
| Backbone | SigLIP So400m/14 ViT, 384 px, frozen | MobileCLIP2-S3 (FastViT convolution–attention hybrid), 256 px, frozen |
| Head | `nn.Linear(1152, 20)`, 23,060 parameters | `nn.Linear(3072, 20)`, 61,460 parameters |
| Total parameters | 428,248,660 | 122,775,668 (3.5 times fewer) |
| Training | `step_head`, weight decay from the four-value grid on validation | the same step, grid and rule (`--steps head_D`) |
| Test accuracy / macro-F1 | 0.823 / 0.817 | **0.773 / 0.770** |
| 95 % bootstrap interval, accuracy | 0.787–0.859 | 0.732–0.811 |
| Validation at the selected epoch | 0.803 | 0.775 / 0.772, epoch 11 of 31 run |

Already on the branch, outside the report: `scripts/itri626_experiments.py` (steps `head_D`, `reference_D`,
`--profile-only`) and the result files under `results/itri626/`. The entries of A, B, C, R1 and R2 were checked to be
unchanged. D's head was scored on the 418 test images once.

## Two things you need to decide first

1. **Is the hybrid an acceptable fourth family?** The brief's list ends with "Swin Transformer or another approved
   image classification architecture". FastViT is a convolution–attention hybrid, not on the named list, so it needs
   the lecturer's approval. A, B and C satisfy the brief without it.
2. **Two sentences in the current text stop being true** once D is in the tables (items 5 and 11).

## Additions, in report order

### 1. Title page and abstract (not counted in the body)

Subtitle: "…a scratch CNN, a fine-tuned ConvNeXt, a frozen SigLIP Vision Transformer and a frozen MobileCLIP 2
hybrid". In the abstract, "Three model families" becomes "Four", and after "(C) a frozen SigLIP So400m Vision
Transformer with a trained linear head" add "and (D) a frozen MobileCLIP2-S3 convolution–attention hybrid, 3.5 times
smaller, with the same head". Scores become "0.400, 0.636, 0.823 and 0.773 (macro-F1 0.392, 0.628, 0.817, 0.770), and
McNemar tests reject equal accuracy for every pair"; the claim that the bootstrap intervals do not overlap goes (see
item 5). Pretraining sentence: "…and frozen web-scale image–text features a further 18.7 with the large encoder or
13.6 with the small one." Last sentence: "We recommend model C, model D where C is too heavy, and ConvNeXt-T for
real-time use on a CPU."

### 2. Section 1, introduction (wording only)

- Aim and scope: "We compare four model families, one trained from scratch and three that use transfer learning
  (fine-tuning, and frozen features from a large and from a small web-pretrained encoder), on one leakage-free…"

- Last finding: "We recommend model C, model D where C is too heavy, or ConvNeXt-T for real-time CPU inference."

### 3. Section 3, new subsection after 3.3 "Model C"

> **3.4 Model D: MobileCLIP2-S3 hybrid, frozen, with a linear head (feature extraction, small backbone).**
> MobileCLIP 2 [new ref] trains image–text encoders for on-device use; its S3 image encoder is a FastViT
> convolution–attention hybrid [new ref] at 256×256 pixels with 122,775,668 parameters, 3.5 times fewer than C (timm
> weights `fastvit_mci3.apple_mclip2_dfndr2b`). It is used exactly as C, with one `nn.Linear(3072, 20)` head trained

Also in Section 3: "The same split files feed all four models", and the workflow figure gains a fourth box
(`figures/fig00_workflow.png` shows it; the TikZ is in the trial build).

In "Rationale", after "…frozen features from web-scale image–text pretraining (C).":

> D repeats C's strategy with a fourth family, a convolution–attention hybrid (the brief's "another approved image
> classification architecture"; A–C satisfy the brief without it).

### 5. Section 5.1 "Overall test performance" (replaces one claim)

"…and the 95 % bootstrap intervals do not overlap" is no longer true for the pair C, D (0.787–0.859 and
0.732–0.811). Proposed first sentences:

> Table 4 gives the test metrics. The ranking is the same for every metric: model C (accuracy 0.823, macro-F1 0.817)
> > model D (0.773, 0.770) > model B (0.636, 0.628) > model A (0.400, 0.392). The 95 % bootstrap intervals of A, B
> and the two frozen models do not overlap; those of C and D do, and the paired comparison separates them. The paired
> comparisons (Table 5) are decisive: B is right where A is wrong on 119 images against 20 the other way, C beats B on
> 92 against 14, D beats B on 80 against 23 (p = 1.5×10⁻⁸), and C beats D on 39 against 18 (p = 7.5×10⁻³).

"Test accuracy is slightly above validation accuracy … for every model" does not hold for D (validation 0.775, test
0.773); "within about two points of" covers all four. At the end of the paragraph on reference rows:

> R3 is the same recipe on D's features (0.806) and is likewise a reference row.
